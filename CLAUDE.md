# CLAUDE.md

Working rules for AI-assisted changes in this repository. They mirror the README; the README wins on conflict.

## Non-negotiable rules

1. **The model reads; the rules decide.** `src/lib/analyzer/claude.ts` is the only place a model is called. What reaches the lawyer is what `src/lib/grounding.ts` let through: a thesis needs an anchor found in the file, a topic the file contains and that the defence has not already won, and (when it asserts a fact) citations the file contains. Do not move a grounding decision back into a prompt, and do not add a path that shows an unverified thesis as verified.
2. **Nothing is discarded silently.** Every thesis the rules remove is reported with its rule and its reason, in the API response, in the store and on the screen.
3. **The prompt and the parser agree.** The SUMMARY TABLE headings in `prompts.ts` are what `parseSummaryTable` reads; a test checks it. Change both or neither.
4. **Demo adapters are selected only in `factory.ts`.** Business code receives built services and never reads `DEMO_MODE`. The fixture analyzer answers only for the sample cases and refuses everything else with an explanation.
5. **Fixtures are fictional.** Invented parties on `.example`-style names, case numbers dated 2099 with invalid check digits, and recorded readings with planted hallucinations that `npm run eval` must catch. `public/samples/*.pdf` are generated by `npm run fixtures` and must match the JSON (CI checks).
6. **Case files are Portuguese; the product is English.** The pleading phrases in `extract.ts` and the anchors stay in Portuguese because they match the file; the UI, the prompts, the logs and the docs are English; the diagnosis language is a setting.

## Conventions

- Next.js 16 (App Router), React 19, TypeScript 5, Tailwind 4, Vitest 5; Node 22.18+ (native type stripping runs the scripts).
- `src/lib` imports its siblings with explicit `.ts` extensions and JSON with `with { type: "json" }`, so `scripts/*.mts` can import the same modules under plain Node.
- Tests exercise the real code (route handlers included) with the rendered sample PDFs; no copies of the logic inside tests.
- Never commit `.env*` (except `.env.example`), `.demo/`, `data/`.
- Commits: English, Conventional Commits, one logical change each, no AI attribution trailers.
